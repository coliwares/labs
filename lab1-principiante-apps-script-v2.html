ANTES DE EMPEZAR

Teoría

Hablemos de Apps Script y la Gema Citizen Builder.

1

¿Qué es Apps Script?

Una plataforma de desarrollo basada en JavaScript que permite automatizar, extender e integrar aplicaciones en Google Workspace sin infraestructura adicional.

2

Script stand-alone y editor

Vive solo en script.google.com, sin estar pegado a ningún archivo (una libreta propia, no un post-it en una planilla). Se usan cuatro piezas: Código.gs, el selector de funciones, el botón Ejecutar y el Registro de ejecución.

3

¿Para qué sirve?

  1. 1. Automatiza tareas: Flujos entre Sheets, Forms, Drive, Calendar.
  2. 2. Conecta servicios: APIs y servicios externos, usando las bibliotecas Citizen.
  3. 3. Crea aplicaciones: Web apps como formularios internos, consulta de datos, usando tu Google Sheet como base de datos.

Gema Citizen Builder

Para qué sirve

Genera el código de Apps Script a partir de una descripción en lenguaje natural. Te entrega el código y el paso a paso para que funcione; tu trabajo es revisarlo antes de ejecutarlo.

Cómo abrirla

Accede con el link de abajo. Si pide cuenta Google, usa tu cuenta corporativa. Pega el prompt del ejercicio directamente en el chat de la gema.

Qué no hace

No ejecuta el código ni lo guarda en Apps Script. El código que entrega puede variar entre ejecuciones. Recuerda que estás trabajando con una IA: mientras más contexto le des, mejor será el resultado.

Abrir Gema Citizen Builder

Un error en rojo no es un fracaso: el Registro de ejecución dice qué línea falló.

La pantalla de permisos es normal. Se lee qué pide y se autoriza solo en el propio script.

LAB1 · Código.gs — solución completa 
/**
 * LAB 1 · Correos automáticos con Apps Script (solución completa)
 * Script stand-alone. Datos ficticios. Envío solo al propio usuario.
 * Proyecto: LAB1 - Correos. (holaMundo del Ejercicio 0 vive en otro proyecto y no se incluye aquí.)
 */

const ZONA_HORARIA = "America/Santiago";

const INSPECCIONES = [
  { area: "Rampa",   tarea: "Revisión de conos y señalética",         estado: "Completada" },
  { area: "Hangar",  tarea: "Orden y limpieza de zona de herramientas", estado: "Pendiente"  },
  { area: "Bodega",  tarea: "Inspección de extintores",               estado: "Pendiente"  },
  { area: "Oficina", tarea: "Revisión de salidas de emergencia",      estado: "Completada" }
];

// ---------- Ejercicio 1 ----------
function enviarCorreoPrueba() {
  const destinatario = Session.getEffectiveUser().getEmail();
  const nombre = "TU NOMBRE";
  const fecha = Utilities.formatDate(new Date(), ZONA_HORARIA, "dd-MM-yyyy HH:mm");

  const asunto = "Prueba LAB1 · " + fecha;
  const cuerpo  = "Hola " + nombre + ",\n\nEste correo lo envió tu primer script.\nFecha y hora: " + fecha;

  MailApp.sendEmail(destinatario, asunto, cuerpo);
  Logger.log("Correo enviado a " + destinatario);
}

// ---------- Ejercicio 2 ----------
function armarHtml(items) {
  const fecha = Utilities.formatDate(new Date(), ZONA_HORARIA, "dd-MM-yyyy");
  const celda = "padding:8px;border:1px solid #ccc;";
  let filas = "";

  for (const item of items) {
    const color = item.estado === "Completada" ? "#1e7e34" : "#b02a37";
    filas += `<tr>
      <td style="${celda}">${item.area}</td>
      <td style="${celda}">${item.tarea}</td>
      <td style="${celda}color:${color};font-weight:bold;">${item.estado}</td>
    </tr>`;
  }

  return `<div style="font-family:Arial,sans-serif;">
    <h2>Resumen de inspecciones · ${fecha}</h2>
    <table style="border-collapse:collapse;">
      <tr style="background:#f1f3f4;">
        <th style="${celda}">Área</th>
        <th style="${celda}">Inspección</th>
        <th style="${celda}">Estado</th>
      </tr>
      ${filas}
    </table>
    <p style="color:#666;">Correo de práctica con datos ficticios.</p>
  </div>`;
}

function enviarResumenTurno() {
  const destinatario = Session.getEffectiveUser().getEmail();
  const pendientes   = INSPECCIONES.filter(i => i.estado === "Pendiente").length;
  const asunto = pendientes > 0
    ? `Resumen de turno: ${pendientes} pendiente(s)`
    : "Resumen de turno: todo al día";

  MailApp.sendEmail({
    to:       destinatario,
    subject:  asunto,
    htmlBody: armarHtml(INSPECCIONES),
    body:     "Tu cliente de correo no muestra HTML."
  });
  Logger.log("Resumen enviado a " + destinatario);
}

// ---------- Ejercicio 3: variante opcional por código ----------
function crearTriggerDemo() {
  eliminarTriggers();
  ScriptApp.newTrigger("enviarResumenTurno")
    .timeBased()
    .everyMinutes(1)
    .create();
  Logger.log("Trigger de demostración creado: un correo por minuto.");
}

function eliminarTriggers() {
  const triggers = ScriptApp.getProjectTriggers();
  for (const t of triggers) {
    ScriptApp.deleteTrigger(t);
  }
  Logger.log("Triggers eliminados: " + triggers.length);
}

Código de referencia · Bonus 
const BUSQUEDA = "in:inbox"; // acótala con operadores de Gmail, p. ej. "in:inbox -category:promotions"
const MAX_HILOS = 50;
const ZONA_HORARIA = "America/Santiago";
const DIA_MS = 24 * 60 * 60 * 1000;

function escaparHtml(texto) {
  return String(texto)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}

// Día hábil anterior: lunes, sábado y domingo -> viernes; resto -> ayer.
// No considera feriados.
function diaHabilAnterior() {
  const hoy = new Date();
  const hoyTexto = Utilities.formatDate(hoy, ZONA_HORARIA, "yyyy-MM-dd");
  const mediodia = Utilities.parseDate(hoyTexto, ZONA_HORARIA, "yyyy-MM-dd").getTime() + 12 * 60 * 60 * 1000;
  const diaSemana = Number(Utilities.formatDate(hoy, ZONA_HORARIA, "u")); // 1 = lunes ... 7 = domingo
  const retroceso = diaSemana === 1 ? 3 : (diaSemana === 7 ? 2 : 1);

  const objetivo = new Date(mediodia - retroceso * DIA_MS);
  const siguiente = new Date(objetivo.getTime() + DIA_MS);
  return {
    inicio: Utilities.parseDate(Utilities.formatDate(objetivo, ZONA_HORARIA, "yyyy-MM-dd"), ZONA_HORARIA, "yyyy-MM-dd"),
    fin: Utilities.parseDate(Utilities.formatDate(siguiente, ZONA_HORARIA, "yyyy-MM-dd"), ZONA_HORARIA, "yyyy-MM-dd"),
    etiqueta: Utilities.formatDate(objetivo, ZONA_HORARIA, "dd-MM-yyyy")
  };
}

function encabezado(mensaje, nombre) {
  const h = mensaje.payload.headers.find(x => x.name.toLowerCase() === nombre.toLowerCase());
  return h ? h.value : "";
}

function enviarResumenDia() {
  const destinatario = Session.getEffectiveUser().getEmail();
  const dia = diaHabilAnterior();
  const desde = dia.inicio.getTime();
  const hasta = dia.fin.getTime();

  // Gmail API (servicio avanzado): hilos con correos entre las 00:00 y las 23:59 de ese día
  const consulta = BUSQUEDA + " after:" + Math.floor(desde / 1000) + " before:" + Math.floor(hasta / 1000);
  const respuesta = Gmail.Users.Threads.list("me", { q: consulta, maxResults: MAX_HILOS });
  const hilos = respuesta.threads || [];
  const conversaciones = [];

  for (const hilo of hilos) {
    // Solo se piden los encabezados (Asunto y Remitente): no se descarga el cuerpo
    const detalle = Gmail.Users.Threads.get("me", hilo.id, {
      format: "metadata",
      metadataHeaders: ["Subject", "From"]
    });
    // Solo los mensajes recibidos ese día (no los enviados por ti)
    const mensajes = (detalle.messages || []).filter(m => {
      const fecha = Number(m.internalDate);
      return fecha >= desde && fecha < hasta && (m.labelIds || []).indexOf("SENT") === -1;
    });
    if (mensajes.length === 0) continue;

    const ultimo = mensajes[mensajes.length - 1];
    conversaciones.push({
      remitente: encabezado(ultimo, "From") || "(desconocido)",
      asunto: encabezado(mensajes[0], "Subject") || "(sin asunto)",
      mensajes: mensajes.length,
      ultima: new Date(Number(ultimo.internalDate)),
      enlace: "https://mail.google.com/mail/u/0/#all/" + hilo.id
    });
  }

  conversaciones.sort((a, b) => b.ultima - a.ultima);
  const totalCorreos = conversaciones.reduce((suma, c) => suma + c.mensajes, 0);
  const asuntoCorreo = conversaciones.length > 0
    ? `Resumen del ${dia.etiqueta}: ${totalCorreos} correo(s) en ${conversaciones.length} conversación(es)`
    : `Resumen del ${dia.etiqueta}: sin correos`;

  const celda = "padding:8px;border:1px solid #ccc;";
  const filas = conversaciones.map(c => `<tr>
    <td style="${celda}">${escaparHtml(c.remitente)}</td>
    <td style="${celda}"><a href="${escaparHtml(c.enlace)}">${escaparHtml(c.asunto)}</a></td>
    <td style="${celda}">${c.mensajes}</td>
    <td style="${celda}">${Utilities.formatDate(c.ultima, ZONA_HORARIA, "HH:mm")}</td>
  </tr>`).join("");

  const html = conversaciones.length > 0
    ? `<div style="font-family:Arial,sans-serif;">
        <h2>Tus correos del ${dia.etiqueta}</h2>
        <table style="border-collapse:collapse;">
          <tr style="background:#f1f3f4;">
            <th style="${celda}">Remitente</th><th style="${celda}">Asunto</th>
            <th style="${celda}">Mensajes</th><th style="${celda}">Hora</th>
          </tr>${filas}
        </table>
      </div>`
    : `<p>No hay correos del día hábil anterior (${dia.etiqueta}).</p>`;

  MailApp.sendEmail({
    to: destinatario,
    subject: asuntoCorreo,
    htmlBody: html,
    body: "Tu cliente de correo no muestra HTML."
  });
  Logger.log("Resumen enviado a " + destinatario + " (" + totalCorreos + " correos, día " + dia.etiqueta + ")");
}

Mejoras para pedir a la gema

  1. 1

    Mostrar al inicio del correo el total de correos recibidos ese día.

  2. 2

    Excluir los feriados al calcular el día hábil anterior (por ejemplo, con un calendario de feriados de Google Calendar).

  3. 3

    Agrupar las conversaciones por etiqueta de Gmail en vez de mostrarlas en una sola lista.

  4. 4

    Marcar en la tabla las conversaciones con más de 3 mensajes ese día.
