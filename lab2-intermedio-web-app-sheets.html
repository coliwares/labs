ANTES DE EMPEZAR

Teoría

Una web app, una hoja de cálculo como base de datos y la Gema Citizen Builder.

1

¿Qué es una web app?

Una página web que vive en Apps Script y se abre con un link, sin instalar nada. Se compone de dos archivos: Código.gs (el servidor, que lee y escribe datos) e Index.html (lo que ve la persona).

2

Sheets como base de datos

Cada fila es un registro y cada columna un campo (la cabecera los nombra). La web app lee esas filas para mostrarlas y agrega filas nuevas cuando alguien llena el formulario. Es una base de datos que cualquiera puede abrir y revisar.

3

El caso del laboratorio

Ocurrencias de Seguridad Operacional con datos ficticios. Subimos de a un escalón:

  1. 0. Calentamiento con un prompt básico.
  2. 1. Ver los datos del Sheets.
  3. 2. Ingresar datos nuevos.
  4. 3. Una web app nueva sobre un archivo existente.

Gema Citizen Builder

Para qué sirve

Genera el código de Apps Script a partir de una descripción en lenguaje natural. Te entrega el código y el paso a paso para que funcione; tu trabajo es revisarlo antes de ejecutarlo.

Cómo abrirla

Accede con el link de abajo. Si pide cuenta Google, usa tu cuenta corporativa. Pega el prompt del ejercicio directamente en el chat de la gema.

Qué no hace

No ejecuta el código ni lo guarda en Apps Script. El código que entrega puede variar entre ejecuciones. Recuerda que estás trabajando con una IA: mientras más contexto le des, mejor será el resultado.

La clave de este laboratorio

La calidad del resultado depende del prompt: pasaremos de una frase suelta a un prompt detallado, y de ahí a pedir cambios sobre lo que ya funciona.

Abrir Gema Citizen Builder

Cambiaste el código, no se ve el cambio: una web app publicada no se actualiza sola. Hay que crear una nueva versión en Administrar implementaciones.

La pantalla de permisos es normal. Se lee qué pide y se autoriza solo en el propio proyecto.

LAB2 · Código.gs — Ejercicios 1 y 2 
/**
 * LAB 2 · Web app con Google Sheets como base de datos (solución completa)
 * Ejercicios 1 y 2: crear el Sheet, ver ocurrencias e ingresar nuevas. Datos ficticios.
 * Proyecto: LAB2 - Safety Occurrences. Archivos: Código.gs + Index.html
 */

const NOMBRE_SHEET = "LAB2 - Safety Occurrences";
const HOJA = "Ocurrencias";
const ENCABEZADOS = ["ID", "Fecha", "Tipo de evento", "Impacto en el vuelo", "Descripción"];
const ZONA_HORARIA = "America/Santiago";
const TIPOS = ["FLT", "HLT", "CAB", "DSP"];
const IMPACTOS = ["Sin impacto", "Bajo", "Medio", "Alto"];

// Ocurrencias ficticias de ejemplo: [días atrás, tipo, impacto, descripción]
const EJEMPLOS = [
  [14, "FLT", "Bajo",        "Turbulencia moderada en crucero; sin lesiones"],
  [12, "CAB", "Sin impacto", "Carro de servicio con freno defectuoso detectado en la revisión previa"],
  [11, "HLT", "Alto",        "Pasajero con malestar durante el vuelo; se pidió asistencia médica en destino"],
  [10, "DSP", "Medio",       "Diferencia en el cálculo de combustible detectada en el despacho"],
  [9,  "FLT", "Sin impacto", "Alerta de tráfico resuelta sin maniobra"],
  [7,  "CAB", "Bajo",        "Luz de lectura inoperativa en tres filas"],
  [6,  "FLT", "Alto",        "Retorno a origen por indicación de falla hidráulica"],
  [5,  "DSP", "Bajo",        "Plan de vuelo presentado con alternativa desactualizada"],
  [4,  "HLT", "Medio",       "Tripulante con mareo durante el servicio; reemplazado en el tramo siguiente"],
  [3,  "CAB", "Medio",       "Cierre dañado en un compartimiento de equipaje durante el despegue"]
];

// ---------- Página ----------
function doGet() {
  return HtmlService.createHtmlOutputFromFile("Index")
    .setTitle("Safety Occurrences")
    .addMetaTag("viewport", "width=device-width, initial-scale=1");
}

// ---------- Acceso al Sheet ----------
// La primera vez crea el Sheet con su cabecera y datos de ejemplo, y guarda su ID.
// Las veces siguientes reutiliza el mismo Sheet.
function obtenerSpreadsheet() {
  const props = PropertiesService.getScriptProperties();
  const id = props.getProperty("SHEET_ID");
  if (id) return SpreadsheetApp.openById(id);

  const ss = SpreadsheetApp.create(NOMBRE_SHEET);
  const hoja = ss.getSheets()[0].setName(HOJA);
  hoja.getRange(1, 1, 1, ENCABEZADOS.length).setValues([ENCABEZADOS]).setFontWeight("bold");
  hoja.setFrozenRows(1);

  const filas = EJEMPLOS.map((e, i) => [
    "OCC-" + String(i + 1).padStart(4, "0"),
    new Date(Date.now() - e[0] * 24 * 60 * 60 * 1000),
    e[1], e[2], e[3]
  ]);
  hoja.getRange(2, 2, filas.length, 1).setNumberFormat("yyyy-mm-dd");
  hoja.getRange(2, 1, filas.length, 5).setValues(filas);

  props.setProperty("SHEET_ID", ss.getId());
  Logger.log("Sheet creado: " + ss.getUrl());
  return ss;
}

function obtenerHoja() {
  const hoja = obtenerSpreadsheet().getSheetByName(HOJA);
  if (!hoja) throw new Error('No existe la pestaña "' + HOJA + '" en el Sheet.');
  return hoja;
}

// ---------- Ejercicio 1: leer ----------
function obtenerOcurrencias() {
  const valores = obtenerHoja().getDataRange().getValues();
  valores.shift(); // quita los encabezados

  return valores
    .filter(f => f[0] !== "")
    .map(f => {
      const fecha = f[1] instanceof Date ? f[1] : new Date(f[1]);
      return {
        id: String(f[0]),
        ts: fecha.getTime(),   // para ordenar
        fecha: Utilities.formatDate(fecha, ZONA_HORARIA, "dd-MM-yyyy"), // las fechas no viajan como Date a la página
        tipo: String(f[2]),
        impacto: String(f[3]),
        descripcion: String(f[4])
      };
    })
    .sort((a, b) => b.ts - a.ts);
}

// ---------- Ejercicio 2: escribir ----------
function registrarOcurrencia(datos) {
  const fecha = String(datos.fecha || "");
  const tipo = String(datos.tipo || "");
  const impacto = String(datos.impacto || "");
  const descripcion = String(datos.descripcion || "").trim();

  // El navegador se puede manipular: se valida otra vez en el servidor
  if (!/^\d{4}-\d{2}-\d{2}$/.test(fecha)) throw new Error("La fecha no es válida.");
  if (TIPOS.indexOf(tipo) === -1) throw new Error("El tipo de evento no es válido.");
  if (IMPACTOS.indexOf(impacto) === -1) throw new Error("El impacto no es válido.");
  if (descripcion.length === 0) throw new Error("La descripción es obligatoria.");
  if (descripcion.length > 300) throw new Error("La descripción no puede pasar de 300 caracteres.");

  const lock = LockService.getScriptLock();
  lock.waitLock(10000); // si otra persona está guardando, espera su turno
  try {
    const hoja = obtenerHoja();
    const ultima = hoja.getLastRow();
    let mayor = 0;
    if (ultima > 1) {
      hoja.getRange(2, 1, ultima - 1, 1).getValues().forEach(r => {
        const n = Number(String(r[0]).replace("OCC-", ""));
        if (n > mayor) mayor = n;
      });
    }
    const id = "OCC-" + String(mayor + 1).padStart(4, "0");
    const fila = ultima + 1;

    hoja.getRange(fila, 5).setNumberFormat("@"); // texto plano: =, +, - o @ no se leen como fórmula
    hoja.getRange(fila, 2).setNumberFormat("yyyy-mm-dd");
    hoja.getRange(fila, 1, 1, 5).setValues([[
      id, Utilities.parseDate(fecha, ZONA_HORARIA, "yyyy-MM-dd"), tipo, impacto, descripcion
    ]]);
    SpreadsheetApp.flush();
    return { id: id };
  } finally {
    lock.releaseLock();
  }
}

/**
 * LAB 2 · Ejercicio 3 · Tablero de solo lectura sobre un Sheet existente (solución completa)
 * Proyecto: LAB2 - Dashboard. Archivos: Código.gs + Index.html
 */

const SHEET_ID = "PEGA_AQUI_EL_ID";   // el ID de tu copia del Sheet existente
const HOJA = "Ocurrencias";
const ZONA_HORARIA = "America/Santiago";
const TIPOS = ["FLT", "HLT", "CAB", "DSP"];
const IMPACTOS = ["Without impact", "Low", "Medium", "High"];

function doGet() {
  return HtmlService.createHtmlOutputFromFile("Index")
    .setTitle("Tablero Safety Occurrences")
    .addMetaTag("viewport", "width=device-width, initial-scale=1");
}

// Lee la hoja usando los nombres de los encabezados (no importa el orden de las columnas)
function leerOcurrencias() {
  const hoja = SpreadsheetApp.openById(SHEET_ID).getSheetByName(HOJA);
  if (!hoja) throw new Error('No existe la pestaña "' + HOJA + '" en el Sheet.');
  const valores = hoja.getDataRange().getValues();
  const encabezados = valores.shift().map(h => String(h).trim());
  const col = nombre => encabezados.indexOf(nombre);

  return valores
    .filter(f => f[col("occurrences_id")] !== "")
    .map(f => {
      const crudo = f[col("occurrence_date")];
      const texto = String(crudo);
      const fecha = crudo instanceof Date ? crudo
        : /^\d{4}-\d{2}-\d{2}/.test(texto) ? Utilities.parseDate(texto.slice(0, 10), ZONA_HORARIA, "yyyy-MM-dd")
        : new Date(crudo);
      const valida = !isNaN(fecha.getTime());
      return {
        id: String(f[col("occurrences_id")]),
        ts: valida ? fecha.getTime() : 0,
        fecha: valida ? Utilities.formatDate(fecha, ZONA_HORARIA, "dd-MM-yyyy") : "",
        tipo: String(f[col("occurrence_type_code")]),
        impacto: String(f[col("flight_impact_type")]),
        descripcion: String(f[col("occurrence_flight_description")] || f[col("occurrence_name")] || "")
      };
    })
    .sort((a, b) => b.ts - a.ts);
}

// tipo: "TODOS" o uno de FLT, HLT, CAB, DSP
function obtenerResumen(tipo) {
  const todas = leerOcurrencias();
  const filtradas = TIPOS.indexOf(tipo) === -1 ? todas : todas.filter(o => o.tipo === tipo);

  return {
    porImpacto: IMPACTOS.map(i => ({ nombre: i, cantidad: filtradas.filter(o => o.impacto === i).length })),
    porTipo: TIPOS.map(t => ({ nombre: t, cantidad: todas.filter(o => o.tipo === t).length })), // siempre los cuatro
    recientes: filtradas.slice(0, 5)
  };
}

Seguridad y referencias

Tres reglas que el facilitador repite al cierre.

La web app queda publicada con acceso Solo yo. Y ojo: SpreadsheetApp pide acceso a tus hojas de cálculo y a Drive, no solo a un archivo; úsala solo en tu cuenta.

El laboratorio usa ocurrencias inventadas. No cargues datos operacionales reales de Seguridad Operacional en un Sheet personal.
